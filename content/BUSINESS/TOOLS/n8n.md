# n8n

Self-hosted, open-source workflow automation platform.

## Links
### Description
Visual workflow builder with 400+ integrations. Can be self-hosted for full data control.
### Download or use
[n8n.io](https://n8n.io)

## Reasoning for
Part of the automation toolbox alongside [[Make]]. Key advantage over Make: self-hosting option for clients with data sensitivity requirements.

Used in:
- AI workflow orchestration (LLM chains, RAG pipelines)
- Client projects at [[PLSoft]]
- Internal automation at [[Qamera AI]]

## Alternatives considered
- [[Make]] — easier UI, but cloud-only
- [[Zapier]] — simplest but most expensive, limited for complex flows
