# Excalidraw

Open-source wirtualny whiteboard do tworzenia diagramów w stylu hand-drawn. Collaborative, end-to-end encrypted, działa w przeglądarce.

## Links
### Description
[excalidraw.com](https://excalidraw.com/) — web app
[GitHub: excalidraw/excalidraw](https://github.com/excalidraw/excalidraw) — source code
[Dokumentacja](https://docs.excalidraw.com/)
### Download or use
Dostępny jako:
- Web app: [excalidraw.com](https://excalidraw.com/)
- npm package: `npm install @excalidraw/excalidraw`
- [[Obsidian]] plugin: [obsidian-excalidraw-plugin](https://github.com/zsviczian/obsidian-excalidraw-plugin)

## Reasoning for
Szybkie tworzenie diagramów, wireframes, schematów architektonicznych w luźnym, hand-drawn stylu. Idealny do:
- Brainstormingu i szkicowania pomysłów
- Diagramów architektonicznych
- Wireframes UI/UX
- Notatek wizualnych

## 🧩 Features:
- 💯 Free & open-source
- 🎨 Infinite canvas
- ✍️ Hand-drawn style
- 🌓 Dark mode
- 📷 Image support
- 😀 Shape libraries
- 🌐 Localization (i18n)
- 🖼️ Export: PNG, SVG, clipboard
- 💾 Open format (.excalidraw JSON)
- 📡 PWA (works offline)
- 🤼 Real-time collaboration
- 🔒 End-to-end encryption

## Alternatives considered
- [[Miro]] — bardziej rozbudowany, ale płatny i nie open-source
- draw.io / diagrams.net — bardziej formalny styl diagramów
- tldraw — podobna koncepcja, inny styl
