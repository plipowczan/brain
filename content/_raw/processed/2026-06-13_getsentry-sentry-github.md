# getsentry/sentry

Sentry is a developer-first debugging platform — detect, trace, and fix issues across applications.

## Products / Features
- Error Tracking — capture and analyze crashes and exceptions
- Performance Monitoring (APM) — trace performance, find bottlenecks
- Session Replay — records user interactions for debugging
- Trace Explorer — distributed tracing visualization
- Uptime Monitoring — application availability
- Log Aggregation — centralized log analysis
- AI-Powered Insights (Seer) — ML-assisted issue analysis and fix suggestions

## Tech Stack
Python (~57.6%), TypeScript (~41.2%), plus HTML, Less, MDX.

## Platform Support
Official SDKs for 20+ platforms: JavaScript, Python, Go, Java, Rust, PHP, Ruby, Dart/Flutter, C#/.NET, and game engines (Unity, Unreal, Godot).

## License & Community
Fair Source — Functional Source License (FSL): source-available, converts to Apache 2.0 after ~2 years. ~44.1k GitHub stars, 556+ dependent projects.

## Deployment
- Cloud (SaaS): sentry.io with free tier.
- Self-hosted: getsentry/self-hosted Docker Compose stack.
