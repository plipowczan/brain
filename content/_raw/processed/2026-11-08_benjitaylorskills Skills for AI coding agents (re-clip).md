## Skills

Skills I use with coding agents for design and motion work.

## Stageshow

[![[51d26fcb1f4ce53d218a9c9870c5fa58_MD5.png]]](https://github.com/benjitaylor/skills/blob/main/.github/assets/stageshow.png)

Helps your agent make faux product UI that looks like the real product: stills, feature cards, cursor demos and bento grids, built in React. It includes guidance on composition and motion, a kit to copy from, examples, and tools that film the result so the agent can check its work.

```
npx skills add benjitaylor/skills --skill stageshow
```
