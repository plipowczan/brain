# posthog/posthog

PostHog is an all-in-one, open source platform for building successful products.

## Products / Features
- Product Analytics — event-based analytics, visualization, and SQL querying
- Web Analytics — GA-style traffic monitoring
- Session Replays — real user interaction recordings
- Feature Flags — controlled feature rollouts
- Experiments — A/B testing with statistical analysis
- Error Tracking — issue monitoring and alerting
- Surveys — template-based and custom surveys
- Data Warehouse — external data integration (Stripe, HubSpot, etc.)
- Data Pipelines / CDP — real-time filtering and destination routing
- AI / LLM Observability — traces, latency, cost monitoring for LLM apps
- Workflows — automation and user messaging

## Tech Stack
Python (53.1%), TypeScript (37.8%), Rust (7.2%), JavaScript, Go, SCSS.

## License & Community
MIT (expat) license, with proprietary code isolated in the `ee/` directory. ~35,000 GitHub stars, ~2,900 forks.

## Deployment
- Cloud (recommended): free tier of 1M events/month plus allowances across other products.
- Self-hosted: one-line Docker hobby deployment, scales to ~100k events/month.
