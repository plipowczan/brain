# How to create mind map
[[LIFE/KNOWLEDGE/INFO/Mind map]]
## 🗒️Task:
How to create a mind map step by step

## 🛠️Prerequisites (if applicable): 
Analog: Pen and paper
Digital: Software for mind map creation:
[[LIFE/TOOLS/Obsidian]] + plugin
[[BUSINESS/TOOLS/Miro]]

Digital options I know work (2026):
- **Obsidian Canvas** (core plugin, built in) — an infinite board where cards can be existing notes; good for maps whose branches point to real notes.
- **Mind-map plugins for Obsidian** — e.g. Markmind, which turns a Markdown outline into a map; the map stays a plain-text file.
- **Excalidraw plugin for Obsidian** — hand-drawn look, good for sketchy maps.
- **Miro** — shared online whiteboard, best for group brainstorming.
- **Paper** — still the fastest for a 5-minute map and the best for a recall drill.

## 📝Instructions:

1. Draw the main topic of the mind map
   The main topic is the issue you want to map, it is the starting point for the whole mind map thoughts. It can be a thought, idea, key word, concept, question, problem.  
2. Add the main branches to your mind map 
   On the branches that come out of the central theme/image should be the main keywords, topics, areas, issues that you want to map.  
3. Add more keywords
   After writing down the most general keywords, around the central topic, include further information, keywords, associations (so-called sub-branches).  
4. Take care of the hierarchy of concepts on the mind map
   The more you move away from the central topic, the more detailed information should be located on the branches.  
5. Try to 'enliven' the mind map by adding colors
   Colors 'enliven' the mind map and make the information on it more appealing to our attention.  
6. Supplement the map with simple drawings, graphics, symbols, icons
   Adding simple drawings to a mind map, is a valuable part of processing information.

### Rules of thumb
- **One keyword per branch.** Whole sentences turn the map back into linear notes.
- **3–7 main branches.** More than that and the map stops being an overview — split it into two maps.
- **Your own words.** Choosing the keyword is where the learning happens; copying a ready map skips that step.
- **Timebox it.** 5–15 minutes for a chapter or a meeting. Colour and icons are optional extras, not the point (see the evidence section in [[LIFE/KNOWLEDGE/INFO/Mind map]]).

### Worked example: mapping a 25-minute talk
Central topic: *"Second brain in 25 minutes"* (an example topic).

1. **Centre:** the talk title.
2. **Main branches (step 2):** Why · Capture · Organise · Use · Demo.
3. **Sub-branches (step 3):** under *Capture* → inbox, fleeting notes, web clipper; under *Organise* → folders vs links, [[Zettelkasten]], PARA from [[LIFE/BOOKS/Building a Second Brain]]; under *Use* → writing, flashcards, AI agents.
4. **Hierarchy (step 4):** the outer ring holds examples and stories, not new topics.
5. **Colour (step 5):** one colour per main branch — it later becomes one colour per section of the slides.
6. **Icons (step 6):** a ⚠️ on the branch I'm least sure of, so I research it first.

The map becomes the outline of the talk. Each main branch is one section, each sub-branch one slide or story.

### Recall drill: using the map to learn
1. Make the map while (or right after) reading.
2. Next day, on a blank page, redraw it **from memory**.
3. Compare with the original and mark what you missed in another colour.
4. Repeat after a few days, then after a week.

Steps 2–4 are retrieval practice with growing gaps — the same mechanism as flashcards. See [[Spaced Repetition and Flashcards from Your Own Notes]].

## Outcome:
By creating a mind map you learn doing so and create materials for further learning.

A finished map is either an **overview** you keep as an entry point to a topic (link it to the detailed notes) or a **drill sheet** you redraw from memory. If it is neither, it was a doodle. That's fine for thinking, but it doesn't need to be kept.
