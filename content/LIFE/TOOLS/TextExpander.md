# TextExpander

Text-expansion utility. You define short abbreviations that expand into full snippets — email replies, code boilerplate, addresses, canned responses. Supports fill-in fields, dates, and clipboard placeholders, and syncs snippets across devices.

## Reasoning for
Removes the friction of typing the same boilerplate over and over. Good for repeated email phrasings, support replies, and frequently reused code or config blocks. The payoff scales with how much repetitive text you produce; for occasional use the built-in expansion features of other tools are usually enough.

## Alternatives considered

- AutoHotkey — scriptable, free, steeper learning curve.
