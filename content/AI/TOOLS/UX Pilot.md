# UX Pilot

AI-powered platforma do **wireframingu i hi-fi designu**. Idea → wireframe → high-fidelity → kod, wszystko w jednym narzędziu. Tworzona przez product designerów Kresimira Retiha dla product builderów.

Claim: "design w 12 sekund" od sketcha, myśli lub importu PRD.

## Reasoning for

Używać gdy:
- Masz hipotezę produktową i chcesz w minutę zobaczyć jak wygląda ekran (np. po decyzji z [[UX RULER]])
- Chcesz wygenerować low-fi wireframe i jednym kliknięciem przejść do hi-fi
- Pracujesz w Figma stack'u — UX Pilot ma **two-way sync** (push/pull designów) i import komponentów dla zachowania design system'u
- Potrzebujesz hand-off do dev'a — eksport kodu i sync z GitHub

## 🧩 Features

- **AI UI generator** — sketch / prompt / PRD → ekran
- **Auto wireframing** — low → high fidelity, jednym kliknięciem
- **Design system import** — Figma components jako custom modele (Now 2.0)
- **Figma two-way connection** — retrieve designs do refinement
- **GitHub code sync** — gotowy kod do repo
- **Flowcharts generator** — AI generuje user flows z promptu

## Alternatives considered

- **v0** (Vercel) — generuje React komponenty, ale nie wireframe-first
- **Galileo AI** — wcześniejszy gracz, podobny pitch
- [[UI UX Pro Max]] — Claude skill generujący design system + reasoning rules (process, nie SaaS)
- Figma AI native — szybko nadrabia, ale węższy scope (głównie autocomplete)
