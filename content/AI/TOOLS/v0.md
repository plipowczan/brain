[[Vercel]]'s AI builder. You prompt it (text or an image/screenshot) and it generates [[React]]/[[Next.js]] UI and increasingly full applications, with output as [[shadcn-ui|shadcn/ui]] + [[Tailwind CSS]] — clean, idiomatic code you can copy into a project or deploy straight to Vercel. It started as a UI-component generator and grew toward whole-app generation, staying tightly integrated with the Vercel/Next.js ecosystem.

## Reasoning for

v0 is the other half of the [[Value Builders]] **Builder track**, alongside [[Lovable]]. I teach it because its output is exactly the Tech-track stack — [[shadcn-ui|shadcn/ui]] + [[Tailwind CSS]] on [[Next.js]], deployable to [[Vercel]] — so UI generated by a non-coder drops cleanly into a hand-coded project. Relative to Lovable, v0 is more UI/component-first (great for screens and design-to-code), while Lovable leans toward a full app with a [[Supabase]] backend; together they cover the Builder-track spectrum. The shared shadcn/Tailwind output is the recurring reason these AI builders interoperate with professional codebases instead of trapping you in a silo.

## Alternatives considered

- **[[Lovable]]** — full-app + Supabase backend focus; v0 is stronger for UI/component generation and Vercel-native flow.
- **Bolt.new** — full-stack in-browser builder; v0 wins on shadcn/Next.js idiomatic output and Vercel integration.
- **[[UX Pilot]]** — AI wireframe/UI generation in the vault; design-to-screen oriented, v0 outputs production React.
- **Figma Make / builder.io** — design-tool-adjacent generation; v0 is code-first.
- **[[21st MCP]]** (formerly Magic MCP) — "v0 in your IDE": the 21st.dev component library inside Cursor/Claude Code/Codex and other MCP clients — search and install components, and generate them on a paid AI plan; component-scoped where v0 goes whole-app.
