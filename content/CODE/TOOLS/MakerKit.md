## 🗒️ Description

Full-stack SaaS Starter Kit oparty na **Next.js 16** (lub React Router 7) z Supabase, Drizzle lub Prisma. Kluczowe feature'y:

### 🧩 Features

- **Authentication** — password, magic link, social logins, MFA
- **Billing & Subscriptions** — Stripe integration + Customer Portal
- **Multi-tenancy** — users belong to multiple organizations, personal accounts
- **Super Admin** — dashboard do zarządzania, impersonation, disable users
- **UI** — Shadcn UI + Tailwind CSS v4, dark/light theme, mobile-friendly
- **Blog & Documentation** — wbudowany blog i help center
- **Emails** — React.Email templates, Resend/Nodemailer (SMTP)
- **E2E Testing** — Playwright
- **SEO-Ready** — out of the box
- **Internationalization** — built-in i18n
- **Plugins** — testimonials, feedback, roadmap, waitlist
- **AI-Agent Optimized** — custom rules for Claude Code, Cursor, Codex + MCP server
- **Figma UI Kit** — included
- **No vendor lock-in** — modular architecture, swap auth/db/payments
